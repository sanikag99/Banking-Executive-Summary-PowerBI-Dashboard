# 🏦 Banking Executive Summary Dashboard

## 🔹 Short Description / Purpose

The Banking Executive Summary Dashboard is an interactive Power BI report designed to analyze banking data and provide a clear executive-level view of customer, account, transaction, and credit card performance. The project demonstrates an end-to-end data analytics workflow, from raw data preparation and database structuring to dashboard development and business insights.

## 🛠️ Tech Stack

* 🐍 **Python (Pandas)** – Data cleaning and transformation
* 🗄️ **SQL (MySQL)** – Data import, database structuring, and querying
* 📊 **Power BI Desktop** – Dashboard development and visualization
* 🧠 **DAX** – KPI calculations and analytical measures
* 🔗 **Data Modeling** – Relationships between banking data tables

## 📁 Data Source

The dataset contains banking-related information including customers, accounts, transactions, credit cards, and other financial attributes. The data was processed and structured to support analysis of banking operations, customer activity, and financial performance.

## 🌟 Features / Highlights

### 📌 Business Problem

Banking data is often spread across multiple datasets and tables, making it difficult to obtain a consolidated view of business performance.

Key questions addressed:

* How are banking transactions performing over time?
* What are the key customer and account trends?
* How do transaction volumes vary across different periods?
* What are the major banking KPIs?
* How can multiple banking datasets be combined into a single analytical view?

### 🎯 Goal of the Dashboard

To build an interactive executive dashboard that:

* Provides a consolidated view of banking KPIs
* Tracks customer, account, and transaction activity
* Identifies trends and patterns in banking data
* Enables interactive filtering and exploration
* Supports data-driven business analysis

## 🔄 End-to-End Data Analytics Workflow

The project follows a complete data analytics process:

**Raw Data → Python/Pandas → SQL Database → Power BI → Analysis & Insights**

### 1. 🐍 Data Cleaning with Python

* Cleaned and transformed raw banking data using **Pandas**
* Prepared datasets for database import and analysis
* Handled data formatting and consistency issues

### 2. 🗄️ SQL Database

* Imported cleaned datasets into **MySQL**
* Structured the data into relevant banking tables
* Worked with customer, account, transaction, and credit card data
* Established relationships between related datasets

### 3. 📊 Power BI Dashboard

* Connected Power BI to the SQL database
* Built an interactive executive summary dashboard
* Created KPIs, charts, filters, and data visualizations
* Used DAX measures for analytical calculations

### 4. 📈 Analysis & Insights

* Analyzed banking trends and performance
* Identified patterns across customers, accounts, and transactions
* Used interactive visuals to support business analysis and decision-making

## 📊 Key Dashboard Components

### 🔢 Key KPIs

* Customer Metrics
* Account Metrics
* Transaction Metrics
* Credit Card Metrics
* Monthly / Yearly Performance Indicators

### 📅 Time-Based Analysis

Analyzes banking activity across different months and years to identify trends and changes in performance.

### 👥 Customer & Account Analysis

Provides insights into customer and account-level activity and distribution.

### 💳 Transaction & Credit Card Analysis

Tracks transaction activity and credit card-related metrics to understand banking usage patterns.

### 🎛️ Filters / Slicers

Interactive filters allow users to explore the dashboard based on relevant banking dimensions and time periods.

## 📈 Business Insights

* Provides an executive-level summary of banking performance
* Helps identify transaction and customer activity trends
* Enables comparison of performance across different time periods
* Consolidates multiple banking datasets into a single analytical view
* Supports faster, data-driven business analysis

## 💡 Key Learning

A dashboard is more than charts and slicers. This project helped me understand that a good dashboard is the **final step of a larger data journey**.

I worked through the complete process:

**Raw Data → Data Cleaning → Database → Data Connection → Visualization → Insights**

The biggest takeaway was that effective dashboards start with **clean, structured, and reliable data**. Each stage of the data analytics process contributes to producing meaningful and actionable insights.
